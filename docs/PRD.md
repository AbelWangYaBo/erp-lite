# erp-lite PRD（v1）

> 参照对象：用友 U9 cloud 的业务主线（进销存 → 生产 → 财务）。定位：**个人自用的轻量制造 ERP**，单租户、单管理员用户、Docker 一键部署。不做商业化。

## 1. 背景

U9 cloud 是面向中大型制造业的完整 ERP（多组织、多工厂、财务总账、工序级成本、审批流），投入为人年量级。个人自用版剥离多组织/审批/复杂成本，保留其核心业务骨架：**基础数据 → 采购 → 销售 → 库存 → BOM/MRP → 生产工单 → 应收应付**，并以现代 Web 技术栈重写 UI。

## 2. v1 范围（In Scope）

### 2.1 基础数据
- 物料主数据：编码（唯一）、名称、规格、单位、分类（原材料/半成品/成品）、默认仓库
- 仓库：编码、名称（数量不限，库存流水按仓库记录）
- 往来单位：供应商、客户（同一张表，type 区分）

### 2.2 进销存主线
- **采购订单 PO**：草稿 → 已审核 → 部分入库 → 全部入库 → 已关闭；可作废（仅草稿/已审核未入库时）
- **采购入库**：引用 PO 生成，生成库存流水（入库）
- **销售订单 SO**：草稿 → 已审核 → 部分出库 → 全部出库 → 已关闭；可作废
- **销售出库**：引用 SO 生成，生成库存流水（出库）
- **库存台账**：每次出入库一条流水（数量、单价、金额、来源单据），物料现存量 = 流水汇总；**移动加权平均**计价

### 2.3 生产主线
- **BOM**：多级（父物料 → 子物料 × 数量），版本化不做，仅当前生效一份（v1 取舍）
- **MRP 运算**：按成品需求（手工录入或来自 SO 汇总）做 BOM 展开，扣除现有库存与在途（已审核 PO 未入库量、已下达 MO 未完工量），输出**建议采购计划**与**建议生产计划**，可一键转 PO/MO 草稿
- **生产工单 MO**：草稿 → 已下达 → 部分完工 → 全部完工 → 已关闭；领料（生成出库流水，按 BOM 标准用量）、完工入库（生成入库流水，入成本按所耗料成本汇总/加权）

### 2.4 财务主线（轻量）
- **应付 AP**：采购入库自动生成应付明细；**应收 AR**：销售出库自动生成应收明细
- **核销**：录入收款/付款记录，与 AR/AP 明细核销（可部分核销）
- **对账单**：按供应商/客户输出期间内发生、核销、余额

### 2.5 记录完整（审计）
- 所有单据走状态机，每次状态流转留痕
- 单据每次修改记录**字段级前后值**（who/when/field/old/new）
- 全局操作日志：登录、单据创建/修改/审核/作废、MRP 运算等关键动作
- 单据一律**不允许物理删除**（草稿可作废，作废亦留痕）

## 3. Non-goals（v1 明确不做）

- 多组织/多公司/多工厂、多币种
- 总账、凭证、会计科目（应收应付止步于业务台账）
- 审批流（单管理员，审核=确认）
- 复杂成本（工序级、分步结转）、先进先出/个别计价
- 打印模板、Excel 导入导出（v2 候选）、移动端
- 多角色权限（数据模型保留 actor 字段即可）

## 4. 关键业务规则

1. **编码规则**：单据自动编号 `PO20261117001` 格式（前缀+日期+3位流水），物料/仓库/往来单位编码手工录入且唯一。
2. **库存不为负**：出库/领料时现存量不足 → 拒绝并报错（v1 不允许负库存）。
3. **审核后不可改**：已审核单据不可编辑行；更正走红冲性质的作废-重开（v1 简化：未执行可作废，已执行可关闭不可改）。
4. **成本闭环**：采购入库单价 = PO 单价；销售出库出库成本 = 当前移动加权平均；MO 完工入库成本 = 领料成本累计 + 人工/制费 v1 手工分摊额（可填 0）。
5. **MRP 一键转单**：建议计划转为 PO/MO 草稿后标记已处理，避免重复转换。

## 5. 验收标准（v1 Definition of Done）

1. `docker compose up -d` 一条命令起全套（db + api + web），前端可访问可操作。
2. 核心闭环可走通：建物料/BOM → 建 PO 入库（库存↑、AP↑）→ MRP 运算 → 建 MO 领料完工（库存结转、成品入账）→ SO 出库（库存↓、AR↑）→ 收付款核销 → 对账单输出正确。
3. 库存台账、现存量、移动加权成本数字与手工核对一致（提供 1 组种子数据作为核对基准）。
4. 任一单据的修改留痕、状态流转留痕、操作日志可查。
5. 后端 pytest 全部通过（含库存不为负、审核后禁改、编号唯一等边界用例）；`docker compose build` 成功。
